# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, please **do not** open a public issue.

Instead, use GitHub's **Security Advisories** for this repository (if enabled) so we can coordinate a private fix. If advisories are not available, open a private discussion with the maintainers and include enough detail to reproduce the issue safely.

We aim to acknowledge reports within 72 hours and provide a remediation plan as soon as possible.
